# Xinnor wizard UI/UX

## Layout, colors, visual ques

**Плюсы:**

- Общий внешний вид визарда
- Спокойные цвета, читаемые шрифты
- Хороший вертикальный ритм (отступы)

**Минусы:**

- Непоследовательность в использовании primary colors
- Бедность графического языка (совсем нет иконок)
